## Reference Facts To Check

- MPS-802 is the Commodore 1526/VC-1526 family printer; CBM 4022/4023 are mechanically related but use IEEE-488 rather than the serial Commodore bus.
- Real hardware defaults to device 4 and can be jumper-selected across a wider device range. Audit whether EMULATORS intentionally restricts to the host's standard printer-device range.
- Real hardware is 8x8 impact dot matrix, 80 columns, 60 characters per second, bidirectional, with 640 horizontal graphics dots and 8 vertical dots.
- Text line spacing is commonly documented as 6 LPI, with graphics spacing documented separately as 9 LPI. Verify the local manual before accepting code comments or web summaries that differ.
- Hardware summaries identify a 6504 CPU, two 6532 RIOT chips, one 6522 VIA, and an 8 KB ROM. Treat these as hardware-tier facts, not requirements for a formatter/PostScript simulation.
- The user guide metadata and examples emphasize formatter strings, secondary addresses, printer messages, OPEN/CLOSE behavior, and data sent through the serial port.

## Implementation-Specific Checks

- Basic mode supports fewer secondary-address functions than PostScript mode: it handles formatter use/definition, message enable/suppress, business mode, reset, and default mode.
- PostScript mode additionally accepts setting lines per page, defining a programmable character, and setting line spacing. `0x06` line spacing is currently left unimplemented in the source; classify it as missing behavior if the requested fidelity includes that feature.
- `MPS802MatrixPrinterFormatter` owns raw `Format*` pointers; audit lifetime/copy behavior carefully if touching formatter storage or returning format lists.
- Formatter data is accumulated until newline. Using a formatter allows visible characters and `0x1d` as a field separator.
- Enhanced width uses `0x0e` to increase repetition count and `0x81` to reset it in the current implementation; verify the exact manual code names before reporting.
- Reverse mode uses `0x12` on and `0x92` off in intent. The current PostScript switch spells reverse-on as `case 0x012`; confirm whether that is equivalent in C++ and whether the intended code is `0x12`.
- Paging uses `0x93` on and `0x13` off in the current implementation. Check against the manual and generated page behavior.
- Programmable character output is selected with `0xfe` after definition in the current implementation. Check byte order and persistence against the manual.
- The PostScript code relies on runtime working directory lookup for `PSMPS802MatrixPrinterI.ps` and `PSMPS802MatrixPrinterII.ps`; rendering failures can be environment/resource issues rather than printer logic bugs.
