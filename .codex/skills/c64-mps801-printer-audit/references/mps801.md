## Local Implementation Map

- `include/COMMODORE/SerialPrinterMPS801.hpp`: declares `MPS801BasicMatrixPrinterEmulation` and `MPS801PostscriptMatrixPrinterEmulation`.
- `src/COMMODORE/SerialPrinterMPS801.cpp`: defines 6x7 glyph tables, control-code handling, basic text output, PostScript byte rendering, tab/dot positioning, and page geometry.
- `include/CORE/MatrixPrinterEmulation.hpp` and `src/CORE/MatrixPrinterEmulation.cpp`: define page/head state, active channels, configuration, paper, and generic print flow.
- `include/COMMODORE/SerialPrinters.hpp` and `src/COMMODORE/SerialPrinters.cpp`: connect LISTEN/SEND/OPEN/CLOSE traps to `MatrixPrinterEmulation::printChar`, `activateFunction`, and `desactivateFunction`.
- `include/COMMODORE/SerialIOPeripherals.hpp` and `src/COMMODORE/SerialIOPeripherals.cpp`: define KERNAL-trap peripheral plumbing and logical channel tables.
- `src/COMMODORE/IOPBuilder.cpp`: selects `MPS801`, `MPS801-PS`, paper options, output filenames, and fallback behavior.
- `PSMPS801MatrixPrinterI.ps` and `PSMPS801MatrixPrinterII.ps`: PostScript runtime resources copied into printer output on first print.

## Reference Facts To Check

- Serial interface is the Commodore 6-pin serial bus with SRQ, GND, ATN, CLK, DATA, and RESET pins.
- Device selector offers normal device 4, second-printer device 5, and test position T.
- Secondary address `0` selects cursor-up graphics/uppercase mode; secondary address `7` selects cursor-down upper/lowercase mode.
- The printer prints capitals, small letters, numbers, Commodore graphics characters, and custom graphics under software control.
- Character matrix is 6x7; text line width is 80 columns; graphics are 7 vertical dots and 480 horizontal dot positions.
- Character and double-width modes use 6 LPI; graphics mode uses 9 LPI.
- MPS-801 is unidirectional and historically Seikosha/Unihammer based; this matters for documentation and fidelity scope, not for a text/PostScript simulation unless mechanical timing is claimed.
- The manual describes a print-line buffer up to 90 bytes. Some web summaries mention 86 bytes; call out this conflict and prefer the manual for emulator behavior.

## Implementation-Specific Checks

- Basic mode intentionally implements only a subset: line feed, double width, standard width, cursor down/business mode, cursor up/uppercase mode, and simple printable-character conversion.
- PostScript mode should be audited for the wider command set: graphics mode, reverse mode, tab setting, dot-address setting, repeat graphic data, and glyph rendering.
- `0x1a` repeat graphic data is currently left unimplemented in the source; classify it as missing behavior if the requested fidelity includes that manual feature.
- Dot address should be bounded by 480 dots and translate into character/head position plus intra-character column.
- `0x0f` standard width also exits graphics mode in the current implementation; verify this against the manual before calling it correct or incorrect.
- The PostScript code relies on runtime working directory lookup for `PSMPS801MatrixPrinterI.ps` and `PSMPS801MatrixPrinterII.ps`; rendering failures can be environment/resource issues rather than printer logic bugs.
