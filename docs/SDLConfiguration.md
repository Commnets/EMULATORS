# SDL configuration

The SDL build configuration reference is now part of the English
[EMULATORS Installation Configuration and First Run guide](../Configure.docx)
at the repository root.

Read that guide for prerequisites, dependency versions and preparation, Windows
environment variables, the SDL selector and header wrappers, linker settings,
validation errors, clean rebuilds, first-run resources and manual DLL and
installer preparation.

SDL2 remains the working baseline. SDL3 dependency selection is prepared;
application API migration is still a separate phase.
