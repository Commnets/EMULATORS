W BLOCKS
Heading 1	/w
Normal	Meaning: Selects the SID audio implementation.
Normal	General form: 
Code	/w[OWN|SID]
List Paragraph	• OWN or an empty value: the framework's ICF/simple SID wrapper (default).
List Paragraph	• SID: the reSID-based wrapper.
List Paragraph	• Any other text is unsupported and may leave the requested wrapper undefined.
Normal	Examples: 
Code	C64Emulator.exe /wOWN
Code	C64Emulator.exe /wSID
Normal	Consequence: The selected wrapper is used when the SID chip is created; it changes sound fidelity and processing cost.
Heading 1	/b
